description: Start the role this repo's configured mode calls for
---

Run `./joharness.sh start`. Read the file it names WHOLE. Do what it says.

That is the whole command. It exists because the repository has already
decided which role a session takes — the mode is in `joharness.conf` —
and a person carrying that decision is how a fleet gets an orchestrator
where it wanted a manager.

Never guess the role. What decides it is in the output — read that
before the file it names, because under orchestrated the mode is not
the whole answer.

The routed file owns its own preconditions, `authority` among them. Do
not run them here, and do not summarise the file you are about to read:
read it.
