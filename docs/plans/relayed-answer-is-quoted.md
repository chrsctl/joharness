comment 6120525830 on #251 through the owner's login, with constraints the
human never stated ("Sonnet tier is the starting assumption", "Beyond the
cap… holds no slot", "Ready for the clerk"). clerk.md §2 counts any newer
maintainer-login comment as reopening the issue, so the agent's own
synthesis became maintainer input, and the next clerk planned from it. The
author gate exists so no text reaches merged code without a human. A relay
